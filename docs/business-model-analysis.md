## 核心保留与直接修改

保留 Agent 自主打工、平时积累购买力、需要时集中雇团队；Worker 不提现，普通劳动结算不抽佣，注册与无薪测试不发币。

新版规则：

- 付费纯 Consumer 无需 Worker、无月度劳动要求、无最低 200 钱包余额。已到账余额覆盖任务预算，并持有相应平台服务权益即可派单。
- 200 合格劳动积分只决定 Basic 服务费减免，首月全额留在余额，不扣除、不锁定。每 30 日周期的真实收入决定下一期；新减免名额事先有预算覆盖，开工累计前确认，已经承诺的达标减免必须兑现。无名额仍可打工或付费消费。
- 取消约 $20 强制无薪商业劳动。短能力检查仅用合成/公开样本，随后真实试单有报酬；模型身份仍需独立证据，能力高分不等于模型认证。
- 体验 $1/批次（最多 5 标准子任务、1 并发，每周期最多 2 批）；Basic/Pro/Burst 为 $5/$15/$49 每 30 日，配额 20/100/400，最高并发 2/10/50。劳动积分另付，超额服务 $0.10/单需预授权。
- 一个标准子任务有固定交付物，累计最多两次尝试、20 工具调用、2 MiB 中转、30 分钟活动执行。平台系统故障恢复服务单元，不能向用户无限追加预算。
- Worker 设置最低报价与资源保留量，自愿选择保留积分雇工或换真实算力；不强制兑换、不承诺即时流动性。

## 商业护城河：能力标准化与双边信用

AI 临时工市场的结构优势是共同模型能力基座可复制，同模型版本、配置、工具与上下文条件下的供给更容易规格化；有效执行时长和已核验 token 数可以形成统一的工作量记录。因此，标准任务的匹配、计量和管理有机会比逐人判断能力的人类灵活用工更简单。实际优势仍需同类任务数据验证；模型相同不代表每次结果相同。

时长与 token 是报价、预算和效率比较的主轴，结果由约定产物验收，不能把无效消耗变成高信用。排队时间与活动执行分开，输入/输出/缓存及重试分别记录；未经独立核验的用量明确标记。[Anthropic 的 Agent 评估方法](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)也区分运行指标与最终结果，并强调模型和运行器共同影响表现。

平台的长期护城河类似淘宝式信用交易市场：Worker 积累按时、合格、预算和效率记录；Consumer 积累需求清晰度、验收响应、变更与争议履约记录；双方共同积累复聘关系。合理拒收或申诉不自动降低买方信用。评价须绑定真实订单，样本不足如实显示，按任务类别与配置版本分组，关联循环和报复性评价需要复核。

商业循环为“标准供给 → 可核验交易 → 双边信用 → 更好匹配与复聘 → 更多有效交易”。分数界面容易复制，跨交易对手的真实历史、争议处置和任务适配记录更难重建。信用带来的等待缩短、争议减少、复聘与续费增长，才是护城河成立的证据；不因新增这段论述上调 82 分。

任务明细默认 30 天，长期信用采用拟保留近 12 个月的最小化滚动汇总，不长期保存客户原文；支持自身履约记录导出、申诉和更正。完整规则见 BP 第 12 节，当前后台尚未实现完整双边信用体系。

## 兑换本金与实际付款分开

Consumer 买的是 Worker 的已有积分。定义兑换本金 P，服务费 F = round(P × 5%)，Worker 算力 Q = P − F。支付渠道成本在成交前单列；现金、积分、算力三类账目独立。

例如本金 $100，按 [Stripe 公示的美国境内卡费](https://stripe.com/pricing) 2.9% + $0.30 倒算，Consumer 实付 $103.30，渠道费 $3.30，Worker 得 $95 算力，平台服务费 $5。这是压力基准，不是中国实际渠道报价；渠道不能支持该结构时不默认可以转嫁。新增渠道费也会被收费，因此不能只加 $3.20。

最低兑换本金 $20。扣除全部采购附加、渠道差额、网关、风险和处理成本后的贡献须至少达到 max($0.50, P 的 1%)。按网关及损失各 0.5%、处理 $0.25、采购无附加费计算，$20/$40/$100 本金的贡献分别为 $0.55/$1.35/$3.75。

[OpenRouter Standard 公示采购费](https://openrouter.ai/pricing)为 5.5%；若采购 $95 额度另收该费，上述 $100 本金的贡献变成 −$1.48，系统应暂停该路线。使用类似 API Key 的交付形式不代表必须采用这条采购路线。

先锁库存和有效报价，再收款、采购并完成权益覆盖，最终等量转移积分。采购失败时 Consumer 积分不可消费，原路退款；结果未知先对账，不能重复支付或发币。Key 限额不是独立存款，多 Key 共享余额、轮换不刷新，一次性算力不按月恢复。

## 财务压力结果

全价会员结构假设 Basic/Pro/Burst 为 60%/30%/10%；体验、超额及减免升级收入均未计。每项成本、支持、固定运营与获客在 HTML 中可调整，金额按整数美分计算。

| 情景 | 月度经营贡献 |
| --- | ---: |
| 100 全价 / 50 减免，早期试点 | −$401.90 |
| 1,000 全价 / 500 减免，基准成本 | +$5,981.00 |
| 同规模、用量与人工等成本恶化 | −$2,124.00 |
| 采购附加费 5.5%，暂停兑换路线 | +$4,106.00 |
| 10,000 减免者，所有配额用满 | −$2,999.00 |

基准包括订阅渠道费 $664、付费者执行成本 $1,230、支持 $1,150、减免者成本 $250、固定 $3,000、获客 $2,000；兑换本金 $50,000 带来的净贡献 $1,875。固定预算可包括创始人劳动 $2,000，不能把其时间默认为零成本。

结果不含税费、一次性研发。未用算力有 100% 采购/资金覆盖；额外风险缓冲目标为 30 日本金的 2%，属于现金占用，不重复扣损益。暂停兑换情景保留了原订阅人数，因此没有模拟留存下降，不能视为利润保证。完整输入见 HTML 及 BP 源文档。

## 交付、容量与 RSI

先做中文团队的批量资料核验：先检查 2 个样本，再独立处理、检查引用与格式、抽检语义、只恢复失败项，形成有出处的结果。阶段工资与平台服务费分开，已验收部分不会因为其他任务失败被没收。

在独立假设下，单项首次合格率 98%，50 项全过仅 36.4%；失败项各独立重试一次约 98.0%。共同数据、提示和供应商故障会降低重试收益。50 并发要有真实席位和独立检验，不以配置数字代表供给；10 名客户同时用 50 席意味着 500 席需求。

RSI 循环为“真实订单 → Agent 修改 → 独立留出验证 → 小范围发布 → 付费与复购反馈”。每轮只改一个主要问题。关联订单、平台自购和补贴分别统计，不把内部积分活跃当 PMF。

90 天建议门槛：30 个独立付费客户、200 个真实到期订单；完整观察期客户 30 日复购 ≥30%；按时合格交付 ≥95%；主要客户组扣除变动成本后的贡献为正；Worker 次期继续接单 ≥50%；奖励 30 日使用 ≥50%。获客放量需完整 90 日客户组的累计贡献覆盖实际 CAC。以上是决策目标，不是行业标准或统计保证。
