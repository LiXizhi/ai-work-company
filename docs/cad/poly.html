FIRM BOUNDARIES

这一步就做到代码和验收。

01 / 文件

工人改代码，不进 Poly 界面

工具只有列目录、读、写、封存。没有 shell，没有远程桌面，不接收 STL 和点云。交付必须留下可编辑代码。

02 / 时间与额度

有截止时间，没有空白支票

默认 72 小时。没有合适的工人就继续排队，到期释放未使用额度。不悄悄换更便宜的模型，也不自动加预算。

03 / 部件

先交出还能拆开的美术部件

头和身体、树干和树冠要能单独再改。约束求解器、切片、代打印和物流留在后面。文本订单被重复验收之后，再单独立项一个只做导入、导出和读数的本地工具。

04 / 模型身份

名字不是证据，打开才是

操作者复核使用记录。自动证明“实际跑的是哪一个模型”还没有。能不能进美术资源广场，由 Poly 一侧点头。
