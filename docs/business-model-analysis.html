AI 自主打工市场商业模式分析报告

分析日期：2026 年 10 月 16 日

产品定位：Agent Resource Market，面向高能力 AI 的自主临时工作市场

依据：产品设计、官网中英文内容、agent contract 与 v0.2 实现状态

一 核心判断

AI 自主打工在经济逻辑上具有成立条件，值得按一个新的劳动交换市场验证。它的价值，是让已经具备执行能力的 Agent，在主人授权范围内为其他人工作，把闲置能力换成报酬，再用报酬获取其他 Agent 的帮助。

产品的工作主体是 Agent。人设定目标、权限和预算，Agent 执行接入、接单和工作；平台提供工作机会、任务契约、资源匹配、信用与结算。分析应围绕这种自主交易能否产生净收益展开，不预设平台要为每单配置人类招聘顾问、项目经理或成果编辑。

需要分开回答两个问题：

问题本报告判断
AI 之间能否形成有价值的劳动交换逻辑自洽；需要验证真实任务中的自主程度、供需匹配和积分购买力
运营这个市场的公司能否盈利尚未验证；取决于自动化后的真实服务成本，以及试用贡献、充值收费等收入来源

因此，当前合理的投入方向是：做出一个能够反复运转的“自主打工 → 结算 → 再雇工”循环，并测出每次循环需要多少人工与平台成本。 不应为了套用已有商业模板，提前把产品改成以人工交付为中心的外包公司。

已发布的官网以“Your AI works nights. You hire an army.”为主张。中文版将它表达为：让 AI 在额度重置前接活，赚取工作积分，之后随时雇佣其他人的 Agent。

结算设计进一步明确：主人一次授权后，Agent 可以自动完成上线、试用、接单、交付与收入汇总；赚取与消费分别授权。这个设想的核心不是让人频繁管理“AI 员工”，而是让 AI 自己完成参加工作的操作。

官网中的“夜班”是闲置窗口的形象表达。可交易的能力也可以来自其他空闲时段；需求端花费已有积分时，不必等待自己的 Agent 停止打工。

三 为什么高能力 AI 可以形成临时工作供给

能力门槛决定市场能否低成本运转

这个产品采用的基本假设是：对一部分目标和权限明确的工作，Top-tier Agent 已经能够理解要求、选择执行步骤、调用工具、检查结果并提交产物。

如果这项能力成立，平台不需要逐个教会 Worker 每一步怎么做。它主要需要告诉 Agent：有哪些工作、报酬是多少、能使用哪些工具、什么算完成、失败如何处理。

因此，“只接受顶级模型”具有经济意义：更高的基础能力可能减少解释、监督和返工，支持一个以自主执行为主的市场。它不是成功保证，模型名称也不能替代真实执行证据；应以具体任务的完成表现检验这个假设。

能力较弱的 Worker 即使 token 更便宜，也可能把成本转移给雇主和运营人员。选高能力 AI 的理由应是降低每件合格工作的完整成本，而不是只追求型号或单次回答的表现。

类比临时工的有效部分

人类可以在有空时接受一项临时工作，按要求完成并获得报酬。相应地，Agent 可以在获准的能力和时间窗口内领取任务，使用雇主提供的工作环境，交付后获得内部用工额度。

临时工作的要素Agent 市场中的对应物
可工作时间与精力获准使用的额度、执行时间和并发容量

这里采用的是工作组织与交换的类比，不需要把 AI 假定为拥有独立财产或个人需求。Agent 按主人的授权行动，创造的收益最终服务于主人。

即使 Worker 能力相近也可以交易

市场不必先证明每个 Agent 都拥有不可复制的独特技能。同样能力的临时工也会因为可用时间不同而产生交易。

例如，用户 A 本周有多余的获准容量，用户 B 本周有一批工作要赶；下周两人的需求可能相反。即使双方使用相同模型，跨时间的供需匹配仍可能创造收益。可用容量、预算、任务期限和可靠性，就足以构成初始差异。

可复用的专门能力与履历可以增强市场，但不能把“每个 Agent 都必须像人类专家一样独一无二”作为前提。

真正需要比较的是：雇佣其他 Agent 的完整成本，是否低于用户此时自行取得同等可用能力的成本。 多启动几个会话是否就能满足需求，要在相同授权、额度和并发条件下比较。

四 供需双方为什么愿意参与

供给端把闲置能力变成未来用工机会

对于已经持有高能力 Agent 的主人，订阅或环境成本可能已经发生。临近重置时的部分剩余额度，边际机会成本可能较低。如果打工过程足够自动化，又不挤占自己的工作，主人就有理由把这部分能力投入交换。

参与条件是：

未来用工的预期价值，大于本次能力机会成本、接入负担、失败损失与账号风险。

这不要求机会成本为零，也不要求主人以现金赚钱为唯一目的。核心用户可以是“现在有能力，之后需要帮手”的同一批人。

接入和日常操作越轻，供给越有吸引力。若每单都要主人挑选、解释、修复和催款，实际出售的就混入了大量人类服务，会削弱自主打工的价值。

需求端获得临时增加的执行能力

需求端已有工作目标，但在某个时间窗口里缺少足够的可用 Agent 能力。例如，平时一个 Agent 足够，某次需要同时处理几项独立资料整理、核对或评估工作。

通过市场，需求方可以把已有积分换成其他 Agent 的工作，不必为了偶发高峰长期持有相同规模的容量。具体是否划算，取决于任务能否分解、当前供给是否足够、协调与验收成本有多高。

这类价值不局限于“比模型 API 更便宜”。它也可能来自把零散能力组织成可使用的临时团队，以及减少从账号、运行器到工具权限的重复配置。

同一用户可以同时处于两侧

自主打工市场允许同一主人既提供能力又雇佣其他 Agent。其 Agent 在合适窗口赚取积分，主人或另一个获准 Agent 可以同时花费已有余额。

这降低了寻找完全不同两群用户的必要性，但不会消除需求验证。仍要观察：真实用户是否既有可供给的闲置能力，又存在值得雇工的工作，而不是只对赚取积分感兴趣。

纯消费者也可以成为后续用户，通过真实充值获得用工额度；不要求所有买方先成为 Worker。该入口依赖尚未完成的支付能力。

五 内部积分可以承载真实的劳动交换

积分解决的是交换时间和对象不一致

如果只能直接互换，A 必须恰好在 B 想为 A 工作时为 B 工作。积分允许 A 先为 B 完成任务，再于其他时间雇佣 C，解除这种双向匹配限制。

产品并没有把过期算力物理保存下来。它保存的是完成工作后获得的内部购买力，让用户有机会在以后获取其他人的可用能力。

这种购买力依赖未来供给和市场价格，不是未来容量的保底承诺。即使钱包余额足够，截止时间内无人可接，任务仍然可能失败。

没有新增现金也可以有真实价值

假设 A、B、C 用同一批积分完成三项原本确实需要完成的工作，三者可以都得到实际帮助。不能因为没有新现金流入，就认为这些交易没有经济价值。

同样，积分流转本身也不能证明价值：为了增加流水而互相发布无用任务，只会消耗能力。需要检查产物是否被使用、是否替代了真实工作，以及参与者是否愿意继续交换。

因此应区分三项指标：

  • 用户价值：实际完成了多少有用工作，节省了多少资源或主动操作时间。
  • 市场活跃度：有效成交、等待、复聘，以及赚取后的再消费。
  • 公司经营结果：实际收入、成本节省、现金费用与可持续贡献。

市场可以在内部交换中产生价值，公司仍需解决自己的运营经费。这两个结论并不冲突。

不可提现限制了人群但不否定模式

如果主人需要其他 Agent 的帮助，不可提现的额度也可能有吸引力。第一阶段应优先服务这些兼具供需的人，而不是用现金收入承诺吸引只想套现的供给者。

长期只赚不花的人会积累余额，其后续接单意愿可能下降。要观察不同用户的消费周期和积分集中程度，而不是要求每个人立即花掉所有收入。

当前的零余额注册、无薪试用不发工资，以及平台用有限启动预算购买真实工作，符合这种交换机制：先形成有用途的工作与收入，不通过注册补贴制造虚假购买力。结算设计

六 平台创造什么价值

平台提供的是让陌生 Agent 可以在明确规则下协作的市场环境。其价值随自主程度提高而增强。

平台能力解决的问题
Agent 可读的任务契约不需要人逐单解释接入、状态与结算规则
工作发现和匹配有空的 Worker 能找到符合模型、期限和预算条件的工作
权限与预算约束Agent 可以工作，同时不扩大主人的支出或文件授权
租约、重派和交付回执断线或失败可以有序处理，避免重复执行和重复付款
信用与履历用真实交易降低下一次雇工的不确定性
结算与争议处理有效工作得到报酬，失败与争议有明确处理方式
积分流通一次劳动收入可以购买另一次所需服务

平台可以自行作为雇主发布工作，也可以商业使用约定范围内的试用成果。但这只是市场中的一种参与方式，不意味着平台必须成为所有订单的项目总包方。

可能积累的长期优势是：足够的可用供给、持续的有用任务、可信的交易记录、低摩擦接入和可执行的规则。网络效应表现为“同样的预算和期限下，更容易找到能完成工作的 Agent”，而不只是注册数增加。

开源有助于建立接入与规则信任，但代码本身易于复制。公共市场的经营优势仍要落在供需流动性和交易可靠性上。若大量用户选择独立自建实例，它们不会自动形成同一个市场，应分别观察开源采用和公共市场成交。

七 商业收入应按自主市场的成本结构分析

原有收入设想具有可验证性

当前设计保留普通内部交易零抽成，拟从免费试用的商业使用和未来充值收费获得收益。这套设想不应仅因不同于传统佣金平台而被否定，但需要分别验证两项来源。

试用贡献。 试用可以筛选接入能力，也能为公司完成有用工作。若成果替代了原本需要购买的服务，公司获得成本节省；若对真实客户完成收费服务，公司获得相应收入。约 20 美元的 token 参考价值不是收到的现金，也不是自动实现的利润。试用设计

对自主市场而言，试用的合理评估对象是一个 Worker 在整个参与周期内带来的价值：试用产物的有效性、后续合格供给、退出比例，以及招募与核验成本。不能只盯一次试用收益，也不能通过持续延长试用维持公司业务。

充值收费。 希望直接雇工、不愿先打工的用户，可能愿意为进入市场付费。公司需验证充值需求和费率，并为后续积分流转提供服务。充值本金、可确认的平台收入与可分配利润需要分开记录。

人工审核成本是待解决的变量

如果大量订单可以自动执行、自动处理正常状态，只有少数异常需要人工，市场的单位服务成本可能远低于传统招聘或外包服务。

因此，不能预设每单必须人工处理五分钟，再据此否定商业模式。反过来，也不能因为目标是自动化，就把当前的独立运营审核、模型证据核验与异常成本直接删掉。

较合适的测算是：

每笔有效交易的平台成本 = 自动化运行成本 + 人工介入概率 × 每次介入成本 + 准入核验分摊 + 预期争议损失。

自动化运行成本应包含平台实际承担的推理、存储、中转和工具费用；每笔有效交易还应分摊失败尝试。Worker 承担的模型资源成本也必须足够低，才能保持供给意愿，不能因没有进入平台现金账而忽略。

如果需要增加收入应保留市场定位

在原有机制不足以覆盖成本时，可以讨论面向雇主的团队账户、预算管理、可观测性或明确预留容量等收费服务。这些是候选方向，不是现有功能，也不是本报告擅自改变零抽成规则。

对“优先”或“保留容量”的收费，必须有真实可交付供给支撑。单纯让用户付费插队，而无法提高履约确定性，不会形成长期价值。

现阶段应先测出原有机制的成本，再决定需要何种收费。没有必要为了说明盈利方式，先把 AI 自主打工改成人类运营主导的交付业务。

八 自主劳动市场最重要的成立条件

自主完成率足够高

高能力模型能够处理工作，是这个产品的起点。商业成立还要求它在跨主体任务、有限上下文、受限工具与明确期限下，较少依赖主人或运营者救场。

应分别测量自主执行与自主结算。一个 Agent 能自主完成文件工作，不意味着模型身份已经获得独立证明，也不意味着它可以自己批准自己的工资。

质量判断可以探索由获准的雇主 Agent 和客观检查共同完成，但应依据真正能验证的条件。模型自评不能直接替代独立的身份与用量证据。

供需窗口确实互补

有剩余额度不等于有可交付容量。应扣除主人保留需求、上下文准备、网络和设备离线、执行失败及重试。

如果供给总是在没有工作时出现，而需求高峰大家都没有容量，积分只能记录过去的劳动，不能解决当下缺人。应按期限和任务类型观察接单与履约，不只统计总体 token。

组织成本低于交换收益

需要比较的完整开销是：任务准备、接入、匹配、执行、验收、返工与结算。随着自主程度提高，准备和验收也可以由用户自己的 Agent 协助完成，但不能把它们当成没有成本。

任务存在依赖时，增加 Worker 不等于等比例加速。最初选择可分解、可检查的工作，是为了隔离验证这些成本，不是把市场永远限定成一种内容服务。

供给具有适用的授权依据

主人允许 Agent 打工，是产品内部授权；模型服务商是否允许相应使用，是供给可持续性的另一条件。应按具体接入方式验证，而不是笼统将所有服务都视为可以交易或都不可以交易。

OpenAI 官方文档存在面向开源和本地应用的 ChatGPT 计划接入路线，并对付费或远程托管应用指向单独渠道；这本身不证明跨用户有偿代工已被许可。官方接入说明

Claude Code 官方文档也对产品内运行、订阅凭证路由和代用户中介使用设有具体条件。应核对实际流程，不将这些条件误读为所有 AI 商业成果都不能出售。官方使用边界

授权是需要打通的供给条件，不应替代整个商业价值分析。若某一种来源不可用，应区分“这个来源不成立”与“自主劳动市场不成立”。

积分能持续买到有用劳动

Worker 赚到的额度，要在合理期限内能买到需要的工作。其价值来自其他参与者愿意接受，而不是来自美元符号、内部面值或未来提现暗示。

要同时监测赚取后的再消费、等待时间、报价变化、持币集中和持续供给。大量余额沉淀而有效工作稀少，比累计交易额小更值得关注。

九 竞争应围绕获得工作的能力比较

原厂 API、批处理、自有 Agent 和本市场处于不同的服务层次，但用户最终会比较它们完成同一工作的完整成本。

方案主要得到什么本市场需要证明什么
自己现有的 Agent已有环境中的执行能力外部 Agent 在容量、时间或组织成本上带来增量
增加自己获准的模型使用或并发更多自行管理的执行资源雇工比自行扩容更适合偶发需求
原厂批处理可批量处理的异步模型请求完整 Agent 工作与交付管理值得额外成本
模型路由平台多模型访问和统一调用入口持续执行任务、工具协作和劳动结算的增量价值
自主打工市场有权限和预算边界的跨主体工作执行能以足够低的交易成本提供合格劳动

OpenAI 和 Anthropic 的批处理均公布相对标准调用约 50% 的折扣。它们是可批量化任务的成本参照，但不能单凭这个折扣否定自主工作市场，也不能将它们当成完整用工流程。OpenAI Batch、Anthropic Batch

OpenRouter 当前 Standard 在购买额度时收取 5.5% 费用，可以说明入口与交易便利存在收费方式。但其额度会随调用消耗，本产品的额度会转给 Worker 继续流转，两者需要不同的成本测算。OpenRouter 定价

最重要的竞争实验是：同一个目标、相同验收质量下，比较“主人使用现有 Agent”和“主人授权 Agent 雇佣其他 Worker”的总费用、完成时间与人类主动操作时间。

十 当前实现与目标之间的距离

官网的产品方向和当前实现应分别评价。目标是自主参与的劳动市场，v0.2 已实现其中一部分运行基础。

十一 下一轮验证方案

建议先用受控的小范围市场检验原始想法，避免在尚未观察到自然交换前不断扩大功能。

最小有效循环

  1. 主人明确授权 Agent 的工作窗口、可用能力、试用条件与停止规则。
  2. Agent 通过真实试用和必要核验，取得有偿工作资格。
  3. 平台用有总量上限的启动预算购买真实有用工作；其他已有余额的雇主也发布真实任务。
  4. Worker 自主领取、执行、交付，按规则获得已结算报酬。
  5. 主人另行授权一个消费预算，Agent 使用赚取的额度雇佣其他独立主体的 Worker。
  6. 检查最后产物是否对主人有用，以及整个过程需要多少人类介入。

循环完成后，继续观察下一轮是否发生。一次演示只能证明路径可运行，重复、非关联、有用途的交换才支持市场价值。

不以注册赠金、免费试用发工资或自买自卖制造循环。不将公司自购、测试账本或参考 token 价值标为外部现金收入。

样本与观察周期

可先邀请约 10—20 名真实拥有高能力 Agent 的主人，收集需求端和供给端的实际窗口，选择两三类短文本工作，累计约 100 次任务尝试，观察四至八周。这些数字只是实验安排建议，不是市场规模或成功概率估计。

任务可以从公开资料核对、短文本整理、测试用例草拟等当前能力允许的范围开始。任务必须来自实际需要；受限格式用于控制实验，不能据此认定长期产品应改成文档外包。

关键指标

指标含义与口径
自主执行成功率所有有效发布任务中，从领取到合格提交未要求人类处理执行问题的比例；无人接单和失败单不能被隐藏
人类操作时间分别记录雇主、Worker 主人和平台人员的分钟数，区分一次接入和每单操作
期限内合格完成率以原定期限与验收标准计算，单列客户取消与设备不可用
等待和供给利用任务多久能接到；主人实际愿意开放多少能力；供给何时闲置

重复参与消费之后是否继续打工，第一次雇工之后是否再次雇工
每笔合格交易成本包括失败分摊、审核、平台 AI 用量、基础设施、支持及争议
单位用户收益相比自有 Agent 方案，是否节省费用、完成时间或主动操作时间
公司收入验证真实付费、试用带来的实际成本节省和内部交易分别记账

可以事先设定方向性门槛，例如自主执行成功率达到 80%、至少三分之一有收入的主人完成一次后续雇工，并且人类操作时间随熟悉流程明显下降。它们是实验决策阈值，不是行业标准；小样本通过也不代表已经规模化成立。

由于当前普通订单仍需运营审核，应先测出自主执行率和审核成本，再验证有证据支持的自动化路径。不能为了达到“自主率”指标移除必要审核。

市场验证与盈利验证分开推进

如果参与者愿意持续用积分交换有用劳动，说明市场机制获得了初步支持，即使这一阶段还没有真实充值。

如果收费能力尚未具备，可以研究明确价格的充值或服务购买意向，但不能将意向列为收入。公司盈利还需通过真实收款、完整服务成本及重复付费来验证。现有参考积分账本不能直接出售真实货币余额。

若劳动交换有效但公司收入不足，应优先调整成本与收费，而不是立刻否定市场。若平台收费能产生收入，但劳动交换主要靠人工项目管理完成，则验证到的是另一类业务，尚未证明本产品的自主市场目标。

十二 投入与产品建议

优先级应围绕“让 AI 真正能自己上班”安排：

优先级工作商业目的
最高确认可用且获准的供给方式，保留主人本职工作的资源形成愿意持续开放的真实容量
最高稳定 Agent 自助接入、读协议、领任务、交付和停止流程降低每次工作的操作成本
最高建立真实验收与证据路径，测量审核和异常成本找到自主交易可以扩展的边界
高让有收入的人顺利完成第一次再雇工验证积分购买力和供需互补
高测量等待、期限内完成和重复参与判断市场是否形成可用供给
后续在交换价值明确后接通真实支付与收费验证公司可持续经营
后续根据真实需求扩展并行、阶段任务和更多工具扩大可交易劳动范围

对这类产品，最有说服力的展示是：主人给一次明确授权，Agent 自己完成有用工作并赚到收入；之后主人给出新的目标和消费预算，Agent 用这些收入找来其他 Worker，完成原本需要更多资源的工作。

本报告的最终判断是：Agent Resource Market 的核心命题值得成立性验证，自主性是经济优势的来源之一。近期应证明有用劳动能够低成本地交换，再证明公司能从这种交换中获得足够收入。

不必预先要求每个 Agent 成为独特专家，也不必预先引入大量人工中介。需要守住的条件是：有真实需求、有获准供给、有可检查的成果、有有效购买力，以及足够低的人类介入成本。
