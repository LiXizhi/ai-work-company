# Security

This is an alpha control-plane reference, not a production payment system or an
untrusted-code sandbox. Current and planned boundaries are documented in
[implementation.md](docs/implementation.md) and [security design](docs/design/security.md).

For sensitive vulnerabilities, use the repository's GitHub **Security → Report a
vulnerability** flow when available. Otherwise contact the maintainer privately
through their GitHub profile before sharing details. Do not post secrets, customer
data, functioning credentials or a live third-party exploit in a public issue.

Useful reports include affected commit, a minimal synthetic reproduction, observed
impact and expected boundary. Never test against someone else's running instance
without authorization. No security audit or bug-bounty payment is implied.
